What this tool does

It is a deal screener. You feed it parcels from tax-sale lists, auction calendars, listing sites and county assessor exports. It computes distance from your Ashford, checks acreage and whether a structure exists, estimates an adjusted market value from the assessment, and flags anything priced at or below your threshold (default 85% of value, meaning a 15% or larger discount).

Why it does not pull listings automatically

A page that runs only in the browser cannot read tax-collector sites, MLS feeds or auction platforms directly. Those sites block cross-origin requests and most have no public API. So the browser version works from data you import or enter, and the Sources & searches tab gives you one-click searches that are pre-filtered to land near your base. The README describes the server component that would automate the collection step later.

Adjusted market value

market value   = assessed value ÷ assessment ratio
adjusted value = market value × market adjustment factor
                 (or the comp-based value you enter, which wins if present)
discount       = 1 − asking price ÷ adjusted value

Connecticut assesses at 70% of fair market value, so a parcel assessed at $70,000 has a derived market value of $100,000. If it is offered at $80,000 the discount is 20% and it passes the 15% test. Rhode Island and Massachusetts assess at 100%. New York equalization rates vary by town, so set the parcel's own ratio when you know it.

Deal types

  • Tax sale / tax deed: municipality auctions the parcel for unpaid taxes. Asking price is usually the opening bid (taxes, interest and costs). Connecticut has a six-month redemption period after the sale.
  • Tax lien: you buy the lien, not the land, and earn interest or foreclose later. Watch the redemption rules.
  • Short sale: lender accepts less than the mortgage balance. Slow, but land short sales often have little competition.
  • Foreclosure / REO / bank-owned: court-ordered sale or a lender selling after taking it back.
  • Auction: estate, probate or absolute auctions run by private auctioneers.
  • Government surplus: town, state, USDA, GSA and Treasury dispositions.
  • FSBO / MLS: ordinary listings; still useful when the asking price is far below assessed value.

Working the list

  1. Import or add parcels. The CSV importer recognises common column names (address, town, acres, assessed value, minimum bid, latitude, longitude, and so on). A template lives in templates/parcels-template.csv.
  2. Fill in coordinates so distance can be computed. The parcel editor has a lookup button that uses OpenStreetMap geocoding.
  3. Check the assessor card for land vs. building value. If building value is zero, mark it land only.
  4. Move parcels through statuses: New → Watching → Contacted → Bidding → Passed or Won.
  5. Export the shortlist as CSV to share.
